How it works

From thought to text in four simple moves.

1
Install and open

Choose Windows or Android below, then launch TurboDictate.

2
Enter your real name

Use the same name on each device so your usage can be recognized consistently.

3
Start listening

Use a Windows hotkey or select the Android TurboDictate voice keyboard.

4
Speak and continue

Stop when finished, then paste, copy, edit, or send your transcription.
